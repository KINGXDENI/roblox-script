# Roblox Executor Scripts

Koleksi script otomatisasi Roblox Executor (Delta, Fluxus, Codex, Wave, Synapse, dll).

## 📁 Daftar Script

| File | Game | Fitur Utama |
| :--- | :--- | :--- |
| **`forest_market_hub.luau`** | Pasar Hutan | Auto Farm Kebun, Auto Dagang Kios (hingga 10 Rak LV5), Auto Masak Kompor (Dapur Terpisah), Meja Pengolahan, Auto Loot Gaib |
| **`cooking_chaos_hub.luau`** | Cooking Chaos | Auto Cook, Quick Recipe Prep & Kitchen Helper |
| **`fish_it_auto_rich.luau`** | Fish It | Auto Fishing & Auto Sell Fish |
| **`iron_soul_dungeon_hub.luau`** | Iron Soul Dungeon | Auto Dungeon, Mob Farm & Auto Claim |
| **`prospeksi_auto_rich.luau`** | Prospeksi | Auto Mining & Ore Collector |
| **`connector.luau`** | MCP Tooling | Roblox Executor MCP Client Bridge |

## 🚀 Cara Menjalankan (Loader)

Setelah di-push ke GitHub, jalankan script langsung di executor menggunakan URL Raw:

```lua
-- Contoh untuk Pasar Hutan:
loadstring(game:HttpGet("https://raw.githubusercontent.com/USERNAME/REPO_NAME/main/forest_market_hub.luau"))()
```
